# Simple Interest Calculator

This is a Bash-based simple interest calculator project, created as part of the final assignment for the GitHub and Git CLI hands-on lab.

## 📌 Project Overview

The project contains a shell script (`simple-interest.sh`) that calculates **simple interest** based on user input for principal, rate of interest, and time.

It also demonstrates proper GitHub project structure and collaboration practices, including:
